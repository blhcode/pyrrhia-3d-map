# Pyrrhia 1:1 Scale 3D Map

Interactive fly-around **and** exportable 3D mesh of **Pyrrhia** (*Wings of Fire*), built at real-world scale from in-book travel times.

## Live map

https://blhcode.github.io/pyrrhia-3d-map/

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173/

## Controls

| Input | Action |
|---|---|
| Orbit / Fly buttons | Switch camera mode |
| Frame whole continent | High orbit overview |
| Click minimap / landmark | Teleport |
| W A S D · Q/E · Shift | Fly |
| Mouse drag | Look / orbit |
| Scroll | Speed / zoom |
| Vertical exaggeration | Relief multiplier |
| Export .glb mesh | Download the 3D model |
| R | Reset overview |
